titulo: O editor de follow-up volta a mostrar o quadro onde se montam os passos
---

Ao abrir um follow-up para editar, a lista de blocos aparecia à esquerda, mas a
área do quadro ficava em branco: não dava para ver nem arrastar os passos. O
quadro tinha ficado com altura zero depois da mudança na barra lateral.

Agora o editor ocupa a altura da tela, como o editor de fluxos.

Nada muda para quem opera o servidor: não há mudança de banco nem passo manual.
