Nova página **Tags** no menu do CRM: crie as tags da empresa, escolha uma cor
para cada uma, renomeie (o nome muda em todos os contatos que já a têm) e
arquive o que não usa mais. Criar e editar é de gerente e admin; o atendente
aplica as tags que existem.

Uma tag pode ser ligada a uma coluna de um Kanban. Aplicar essa tag num
contato leva o negócio dele para a coluna — ou cria o negócio ali, se ele
ainda não estava naquele Kanban. E o caminho inverso: mover um card para a
coluna dá a tag ao contato. Nenhum dos dois remove tag sozinho.

As tags que já existiam nos contatos, negócios e conversas aparecem na página
com uma cor escolhida automaticamente. As tags de conversa passam a valer
também para o contato da conversa.

Nada a fazer para atualizar: a atualização cria o catálogo a partir das tags
que você já usa.
